# Results and report index

Use [heldout_validation.md](tables/heldout_validation.md) for the fixed held-out model comparison; [conservation.md](tables/conservation.md) for continuous features, the corrected gate, preserved original failure, and descriptive previews for repression, scrambled-pair dynamic range and cross-context robustness; [gate_metrics.md](tables/gate_metrics.md) for matched ON/OFF operating regions and rankings, [analysis_dataset.md](tables/analysis_dataset.md) for continuous activity and context selection, [scoring_validation.md](tables/scoring_validation.md) for score/sign validation and its binary-label limitation, and [pilot_mouse_evidence.md](tables/pilot_mouse_evidence.md) for the frozen mouse comparison result. These address different endpoints and should be read together.

“Current” means the report remains the evidence for its stated scope. It does not assert that the edited source has been rerun. “Superseded” identifies an interpretation or implementation-state claim replaced by the named report; source observations and recorded receipts are retained. Filenames remain stable evidence references.

## Bounded organization decisions

Analysis and scientific validation belong in `src/`, including importable functions and command-line orchestration. `scripts/` contains operational shell utilities and standalone renderers of saved results. No package hierarchy has been restructured, and no classification code has been deleted.

### Moves applied

| Original location | Canonical location | Reason and compatibility |
| --- | --- | --- |
| `scripts/validate_scoring_activity.py` | `src/scoring_validation.py` | This is reusable scientific scoring/sign validation, with tests and a gate manifest, rather than a standalone presentation script. `make scoring-validation` invokes the canonical module. The original module command remains a thin compatibility entry point. |
| `src/io_mpra.py` | `src/mpra_schema.py` | The implementation validates an explicitly mapped, complete element/cell schema. It is not the production context-preserving MPRA reader. The canonical module's docstring states the missingness and enhancer limitations; `io_mpra.py` retains public compatibility imports. Its tests are named `test_mpra_schema.py`. |
| `src/models.py` | `src/model_scaffold.py` | The former name suggests fitted production models, but these are unimplemented model functions and the legacy binary-label evaluator. `models.py` retains compatibility exports. The fitted rank-linear models are in `heldout_validation.py`. Existing tests moved to `test_model_scaffold.py` and exercise the canonical module. |
